# Torre Mestre

Jogo local de montar torres, em rodadas. Abra o arquivo `index.html` no navegador (no computador ou no celular) para jogar.

## Modos
- **Contra IA**: você contra 3 IAs (4 jogadores), com dificuldade Fácil, Médio ou Difícil
- **Local 2 / 3 / 4**: 2 a 4 pessoas jogando no mesmo aparelho, cada uma na sua vez

## Regras
- Cada rodada, cada jogador solta **um bloco** na sua torre.
- Toque na tela, clique ou aperte **ESPAÇO** para soltar o bloco.
- A parte do bloco que fica para fora é cortada.
- Encaixe perfeito = **Perfeito!**. Com 3 perfeitos seguidos, o bloco volta a crescer.
- Se o bloco cair fora da torre, você perde uma ❤ (cada um tem 3). Sem ❤, está eliminado.
- O bloco fica mais rápido a cada rodada.
- Depois de 10, 15 ou 20 rodadas, vence a torre mais alta. Em caso de empate, ganha quem fez mais perfeitos.
